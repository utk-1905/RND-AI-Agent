# Project Review Rules

This is a modular AI Agent system.

Codex must follow these rules:
- Do not modify files unless explicitly asked.
- For review tasks, generate a report only.
- Do not rename folders or files.
- Do not change UI text or project content.
- Do not rewrite existing content unless requested.
- Focus on architecture, workflow, code quality, scalability, security, and deployment readiness.
- The project uses React + Vite + Tailwind CSS for frontend.
- The backend uses Node.js + Express.js.
- The database uses Supabase PostgreSQL.
- The current active module is the SEO AI Agent in mock mode.
- Claude integration will be added later.
- The system should follow one backend, one database, multiple agent modules, and CEO orchestrator at the top.
- All reviews should be honest, critical, and prioritized by severity.
